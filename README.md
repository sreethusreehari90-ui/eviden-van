### Project Description
[Face to Wild is an AI-powered wildlife counterpart discovery engine. Users glance into their webcam or upload a selfie, and multimodal vision models scan their facial contours, eye shape, and smile to assign them an animal, bird, or insect match (complete with compatibility score, playful reasoning, and wildlife trivia)—all with strict in-memory privacy and zero image persistence.
]

### The Problem (that doesn't exist)
[Humans have spent thousands of years assuming they belong to society, completely oblivious to whether their Monday morning expression actually radiates the majestic aura of a Siberian Tiger or the perpetually startled bewilderment of a Barn Owl. Humanity is suffering from an existential wildlife identity deficit, and traditional personality tests refuse to address whether someone's cheekbones qualify them to lead a wolf pack or blend in with chameleons.
]

### The Solution (that nobody asked for)
[An instant, zero-hesitation browser biometric scanner that captures a single frame of your face, sends it through Google Gemini’s multimodal vision pipeline, and reveals your spirit creature in under five seconds. Complete with real-time camera stream controls, biometric alignment reticles, playful similarity metrics (50%–99%), custom vector creature badges, and instant social share cards.
]

### Technologies/Components Used
For Software:
Languages used: TypeScript (ES2022+), JavaScript, HTML5, CSS3
Frameworks used: React 18, Express.js (v4 backend proxy)
Libraries used:
@google/genai (Official Google Gemini SDK)
motion/react (Smooth UI and modal animations)
lucide-react (Interface and wildlife iconography)
canvas-confetti (Match celebration particle physics)
tailwindcss (Styling and responsive layouts)
Tools used: Vite 6, esbuild, Docker, Node.js v20

# Clone the repository

# Install dependencies
npm install

# Set up environment variables
cp .env.example .env
# Edit .env and supply your free Gemini API key:
# GEMINI_API_KEY=your_gemini_api_key_here

# Run
# Development mode (launches Vite + Express on port 3000)

# Production build and run
npm run build
npm start
